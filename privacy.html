권한과 데이터의 사용

적용 도구: Yoon YouTube Upload. 현재 개인 채널 운영자를 위한 로컬 게시 자동화에 관한 안내입니다.

접근하는 정보와 목적

이 도구는 YouTube API Services를 사용합니다. 운영자가 허용한 youtube.upload 및 youtube.readonly 권한으로 채널 ID·핸들, 기존 영상의 제목·설명·영상 ID·공개 상태 등 게시 확인에 필요한 정보를 조회하고, 운영자가 선택한 영상 파일과 게시 메타데이터를 Google YouTube에 전송합니다.

목적은 대상 채널 확인, 중복 방지, 승인된 영상 업로드와 결과 확인입니다. Gmail·주소록·결제 정보는 이 게시 기능의 권한으로 요청하지 않습니다. Google 비밀번호를 수집하거나 저장하지 않습니다.

저장과 보안

OAuth 갱신 토큰은 운영자 Windows PC의 현재 사용자 DPAPI로 암호화해 저장합니다. 게시 기록에는 채널·영상 ID, 공개 URL, 파일 해시, 확인 시각과 검수 결과 등이 포함됩니다. 인증 토큰 원문을 게시 설명이나 공개 사이트에 넣지 않습니다.

작업 파일과 게시 기록은 승인된 운영·검수 목적에 필요한 동안 운영자 PC에 보관됩니다. 운영자는 필요 없어진 파일과 암호화된 인증 정보를 삭제할 수 있습니다. 권한이 유지되는 동안에도 API로 현재 채널과 게시 상태를 새로 조회합니다.

전송 및 외부 서비스

영상·게시 메타데이터·OAuth 요청은 기능 수행에 필요한 범위에서 Google 서비스로 전송됩니다. 자동화는 ChatGPT/Codex에서 수행되므로 운영자가 요청한 작업의 채널 정보와 게시 메타데이터가 해당 작업 맥락에서 처리될 수 있습니다. 인증 토큰 원문을 대화에 출력하지 않도록 구성합니다.

이 도구가 조회한 Google 사용자 데이터를 광고 타기팅이나 판매 목적으로 이용하지 않습니다. 이 안내 사이트에는 별도 광고·분석 스크립트·회원가입·쿠키 설정 기능을 넣지 않습니다. 웹 호스팅 및 연결된 외부 서비스는 각 제공자의 정책이 적용됩니다.

권한 철회·데이터 삭제

Google 계정의 연결된 앱 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 권한을 철회하면 새 인증 없이는 API 기능을 사용할 수 없습니다.

권한 철회와 별개로 로컬 PC에 저장된 작업 파일·게시 기록·암호화된 인증 파일의 삭제를 운영자에게 요청하거나, 운영자가 직접 삭제할 수 있습니다. 게시된 YouTube 영상의 삭제나 공개 상태 변경은 YouTube Studio에서 관리합니다. 권한 철회가 이미 게시한 영상을 자동으로 삭제하는 것은 아닙니다.

문의와 변경

개인정보·접근 권한·로컬 데이터 삭제 관련 문의는 운영자 문의에서 할 수 있습니다. 공개 문의에는 비밀번호·토큰·민감한 개인정보를 적지 마세요. 접근 범위나 사용 목적을 변경할 때 이 안내와 필요한 동의 내용을 갱신합니다.
